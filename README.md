#  Customer Churn Analysis(Interactive Dashboard Creation Using Power BI)

##  Project Overview

This project is an end-to-end **Customer Churn Analysis Dashboard** developed using **SQL Server** and **Power BI**. It focuses on cleaning, transforming, and analyzing customer data to uncover churn trends and deliver actionable business insights through interactive visualizations and KPIs.

## Dataset Used
[Customer_Data.csv](Customer_Data.csv)

## Project Objectives

* Analyze customer data across demographic, geographic, payment, and service dimensions.
* Identify customer churn patterns and key business insights.
* Build an interactive Power BI dashboard for data-driven decision-making.
* Track customer performance using essential KPIs.

## Technologies Used

* SQL Server
* Power BI
* Power Query
* DAX

##  Key Performance Indicators (KPIs)

* Total Customers
* Total Churn
* Churn Rate
* New Joiners

##  Project Workflow

1. Import and prepare customer data using SQL Server.
2. Transform and clean data with SQL and Power Query.
3. Create KPIs using DAX.
4. Build an interactive Power BI dashboard.
5. Generate business insights from customer churn analysis.

##  Business Insights

* Identify customer churn trends.
* Analyze customer behavior across different segments.
* Monitor customer retention using key performance metrics.
* Support business decisions with interactive dashboards.
